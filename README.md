# UK Housing Market Analysis Dashboard

Interactive Power BI dashboard analyzing UK regional housing market trends, sales performance, property price movements, forecasting, and advanced analytical insights.

---

# Dashboard Overview

This project demonstrates the development of a multi-page interactive Power BI solution focused on regional housing market analysis across multiple UK regions.

The dashboard combines business intelligence, trend analysis, forecasting, statistical analysis, and advanced Power BI features to provide a complete analytical reporting experience.

---

# Business Objective

The goal of this project was to:

- Analyze regional housing sales performance
- Identify high-performing and low-performing regions
- Compare different property categories
- Track yearly and quarterly market trends
- Detect anomalies and forecast future trends
- Demonstrate advanced Power BI analytical capabilities
